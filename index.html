Letra Support

Letra used to be called Nib. Same app, same library and settings: only the name changed.

Select a word on your Mac. See it in your language. Keep it.

Questions, bugs or ideas: xhuseyincakmak@gmail.com

Letra's icon doesn't appear, or can't read the text

  • Check that capture is on: click the pen icon in the menu bar; Capture selections should be switched on.
  • Check both permissions in System Settings → Privacy & Security: Input Monitoring (to show the icon) and Screen & System Audio Recording (to read the text), with Letra switched on in each. After switching them on, quit and reopen Letra.
  • Prefer no permissions? Select text and press Shift-Command-K, or right-click it → Services → Look Up in Letra. (Some apps, like Claude or WhatsApp, don't support Services; the icon works there.)

No translation appears

Letra uses Apple's on-device translation, which needs the language pack for your language. Open Set Up… from Letra's menu and download it, or add your language in System Settings → General → Language & Region → Translation Languages. You can change the language in Letra's Settings.

No explanations

Plain-English explanations use Apple Intelligence, so they need a Mac that supports it, with Apple Intelligence switched on in System Settings. Without it, Letra still translates and shows definitions.

Where is Letra?

Letra lives in the menu bar (a pen icon) and has no Dock icon. Its library opens from the menu bar icon → Open Library.

Privacy

Letra collects no data. Everything runs on your Mac. Read the privacy policy.
